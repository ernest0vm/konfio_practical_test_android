# Dogs We Love

"Dogs We Love" is an Android application designed to showcase various dog breeds, their descriptions, and other related information. The app is built using modern Android development practices, including Jetpack Compose, Retrofit for network operations, and Room for local data storage.

## Features

- **Jetpack Compose**: Utilizes Jetpack Compose for building the UI, providing a modern and efficient way to create Android UIs.
- **Retrofit**: Integrates Retrofit for handling REST API calls to fetch dog-related data.
- **Room Database**: Uses Room for local data storage, allowing offline access to dog information.
- **Material Design**: Implements Material Design components for a consistent and visually appealing user interface.
- **Coroutines**: Leverages Kotlin Coroutines for asynchronous programming, ensuring smooth and responsive user interactions.

## Getting Started

### Prerequisites

- Android Studio Flamingo or later
- JDK 17
- Gradle 8.10.2

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/ernest0vm/konfio_practical_test_android dogs-we-love
   cd dogs-we-love
   ```

2. **Open the project in Android Studio**:

   - Open Android Studio.
   - Click on `File > Open` and select the `dogs-we-love` directory.

3. **Build the project**:

   - Click on `Build > Make Project` or use the shortcut `Ctrl + F9`.

4. **Run the app**:
   - Connect an Android device or start an emulator.
   - Click on `Run > Run 'app'` or use the shortcut `Shift + F10`.

## Project Structure

- **app/src/main/java/com/example/dogswelove**: Contains the main source code, including UI components, data models, and API clients.
- **app/src/main/res**: Contains the resource files such as layouts, drawables, and values.
- **app/build.gradle**: Module-level build configuration.
- **gradle/libs.versions.toml**: Manages library versions and dependencies.

## Dependencies

- **AndroidX Libraries**: Core libraries for Android development.
- **Retrofit**: For network operations.
- **Room**: For local database management.
- **Glide**: For image loading and caching.
- **Kotlin Coroutines**: For managing background tasks.
